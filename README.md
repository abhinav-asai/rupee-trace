# Rupee Trace

> Every Rupee Has a Purpose.

Rupee Trace is a financial coaching platform that helps people allocate every rupee before spending, build mindful financial habits, and improve their financial confidence over time.

## Vision

Help people make intentional financial decisions instead of wondering where their money went.

## Tech Stack

- Next.js
- React
- Tailwind CSS
- Supabase
- PostgreSQL
- Vercel

🚧 Currently in development.
